# 📱 Google Play Store Data Analysis

An interactive data analysis project built using Python to explore Google Play Store applications and understand app ratings, categories, installs, and pricing.

## 📊 Project Overview

This project analyzes Google Play Store data using Python, Pandas, Matplotlib and Streamlit. It includes data cleaning, exploratory data analysis (EDA), visualizations, and an interactive dashboard.

## 🎯 Project Objectives

- Analyze app categories and ratings.
- Compare free and paid applications.
- Explore app installation trends.
- Identify highly installed applications.
- Build an interactive dashboard for data exploration.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit
- Plotly

## 📈 Dashboard Features

- Total Apps
- Average App Rating
- Total Installs
- Paid Apps
- Top 10 App Categories
- App Rating Distribution
- Free vs Paid Apps
- Top 10 Apps by Installs
- App Data Preview

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/manisha05saini/Google-Play-Store-Data-Analysis.git
```

2. Open the project folder:

```bash
cd Google-Play-Store-Data-Analysis/Google_Play_Store_Analysis
```

3. Install required libraries:

```bash
pip install pandas matplotlib streamlit plotly
```

4. Run the analysis:

```bash
python analysis.py
```

5. Run the interactive dashboard:

```bash
python -m streamlit run app.py
```

## 📌 Project Results

The cleaned dataset contains 10,357 applications. The dashboard provides interactive visualizations to explore application ratings, categories, installation trends, and pricing.
